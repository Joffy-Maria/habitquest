💾 Backup & restore

Copy the code somewhere safe, or save a file. To restore, paste a backup code and press Restore (this replaces current data except your password).

📤 Share / 📥 Import

To share: copy this code and send it to a friend who uses Habit Quest. To import: paste a friend’s code and press Import.

🔐 Password lock (optional)

Type a password and press Set. To remove the lock, type your current password and press Remove. This is a privacy lock for this browser, not encryption, and there is no recovery if you forget it.
